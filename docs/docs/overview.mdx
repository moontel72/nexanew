## How to use this manual

- **Books** — each module is split into numbered *Books*. Start at
  **Book 0 (Prerequisites)** — everything there must be ready before you
  touch any operational button.
- **Bilingual sections** — every procedure is written in **English** and
  **Roman Urdu** (side-by-side tabs). Ground operators can follow the
  Urdu tab without translation.
- **Step badges** — steps are numbered exactly as the buttons appear on
  screen (e.g. `Dashboard → Team Management → Add New Team`).

## Printing / PDF for the field

Every page is **print-ready**: press `Ctrl+P` in the browser and choose
**"Save as PDF"** — navigation menus are removed automatically and only
the manual text is printed, so a whole Book can be printed for ground
crews working offline.

> **Roman Urdu:** Har page print ke liye tayyar hai — browser mein
> `Ctrl+P` dabayen aur "Save as PDF" chun len. Menu khud hatt jata hai,
> sirf manual ka text print hota hai — ground crew offline bhi parh
> sakti hai.
