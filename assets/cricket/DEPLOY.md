# ─── NEXATRACE CRICKET — FRONTEND DEPLOYMENT GUIDE ──────

## Architecture

Cricket is **integrated into the shared Flutter app** — no separate entry point.
- Public pages at `/cricket` route (tournament home, live match)
- Manager panel inside `/sub-admin/dashboard` (cricket_ops vertical)

## Build Commands

```bash
# Standard shared app build (includes cricket)
flutter pub get
flutter build web --release

# Deploy to Hetzner
rsync -avz --delete build/web/ root@135.181.46.27:/var/www/traceodd/frontend/
```

## Environment Configuration

Cricket uses the shared `ApiClient` and `WebSocketHub` — same auth tokens,
same base URL, same WebSocket connection as the rest of the ecosystem.
No separate configuration needed.

## PWA Setup

1. The shared `web/manifest.json` is used
2. Service worker is auto-generated by Flutter (`flutter_service_worker.js`)
