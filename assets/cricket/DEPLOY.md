# ─── NEXATRACE CRICKET — FRONTEND DEPLOYMENT GUIDE ──────

## Build Commands

```bash
# Public Cricket Portal (cricket.traceodd.com)
flutter pub get
flutter build web --release -t lib/main_cricket.dart --base-href /

# Copy cricket PWA manifest (overrides default manifest)
cp assets/cricket/manifest.json build/web/manifest.json

# Deploy to Hetzner
rsync -avz --delete build/web/ root@135.181.46.27:/var/www/traceodd/cricket-web/
```

## Entry Points

| File | Target | Purpose |
|------|--------|---------|
| `lib/main_cricket.dart` | `cricket.traceodd.com` | Public tournament portal + PWA |
| `lib/main.dart` | `traceodd.com` | Main admin panel (existing) |

## PWA Setup

1. The cricket build uses its own `manifest.json` in `assets/cricket/`
2. Icons (192px and 512px) should be placed in `web/icons/cricket-icon-*.png`
3. Service worker is auto-generated by Flutter (`flutter_service_worker.js`)
4. Test PWA: Open `cricket.traceodd.com` on mobile Chrome → "Add to Home Screen"

## Environment Configuration

Base URLs are hardcoded in `lib/main_cricket.dart`:
- REST API: `https://cricket.traceodd.com`
- WebSocket: `wss://cricket.traceodd.com`

For local development, change to:
- REST API: `http://localhost:8000`
- WebSocket: `ws://localhost:8080`
